# 런치 룰렛 🎰

점심 메뉴를 결정하지 못할 때, 룰렛으로 선택해 주는 웹 앱입니다.

## 기능

- 🎡 캔버스 기반 룰렛 휠 (부드러운 감속 애니메이션)
- ➕ 메뉴 추가 / 삭제 (최대 20개)
- 🎊 당첨 결과 표시 + 컨페티 효과
- 📱 모바일 반응형

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 접속

## 기술 스택

- [Next.js 15](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS v4
- Google Fonts — Black Han Sans, Noto Sans KR
