# 판교Pick

판교테크노밸리 주변 점심·회식 장소를 룰렛으로 결정해 주는 웹 앱입니다.

## 기능

- 점심 / 저녁 회식 모드 전환
- 회식 카테고리 필터 (소/돼지, 양/닭, 해산물, 샤브/훠궈, 호프/주점, 뷔페, 기타)
- 캔버스 기반 룰렛 휠 (부드러운 감속 애니메이션)
- 결과 모달: 음식점 정보 + 네이버 맵 길찾기 연결
- 모바일 반응형

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 접속

## 기술 스택

- [Next.js 15](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS v4
- Google Fonts — Black Han Sans, Noto Sans KR
